# Simple Node.js App

A basic Node.js application that runs an HTTP server.

## Features
- Lightweight HTTP server
- Responds to requests with a greeting message
- Easy to run and extend

## Installation

```bash
npm install
```

## Running the App

```bash
npm start
```

The server will start on `http://localhost:3000/`

## Usage

Once running, open your browser or use curl to visit the server:

```bash
curl http://localhost:3000/
```

You should see the response: `Hello World! Welcome to the Node.js app`
